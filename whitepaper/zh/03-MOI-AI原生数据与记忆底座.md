# 第二章 MatrixOne Intelligence：AI 原生数据与记忆底座

## 2.1 MOI 概述与定位

矩阵起源自成立以来，始终以"为数字世界提供简捷强大的数据智能操作系统"为使命，致力于让企业和用户简单、敏捷、高效地拥抱数据价值。**MatrixOne Intelligence（MOI）** 正是这一使命在 Agentic AI 时代的集中体现。

MOI 是一套面向多模态数据的 **AI 原生数据智能平台**，其定位是企业的 **下一代 Data Infrastructure（数据基础设施）**。它要解决的，正是第一章所述的核心矛盾——让分散、异构、缺乏治理、没有记忆的企业数据，转变为能被 AI Agent 实时、可信、可追溯地消费的"AI-Ready 数据与记忆底座"。

在技术坐标系上，MOI 对标国际领先的 **Databricks + Snowflake**，但走的是一条根本不同的路线：

- **AI-Native（AI 原生）**：从第一行代码起就为多模态数据与 AI/Agent 负载设计，而非在传统数仓上做加法；
- **超融合（Hyper-Converged）**：以单一引擎统一承载 OLTP、OLAP、向量、全文、时序等多种负载，消灭数据孤岛与 ETL；
- **Git-for-Data（数据的 Git）**：把版本管理、分支、回滚、审计等软件工程理念原生引入数据层；
- **Agent-Native Memory（Agent 原生记忆）**：内置面向 Agent 的长期记忆与上下文供给能力。

一言以蔽之，MOI 不只是"又一个数据平台"，而是 **专为 Agent 而生的数据与记忆底座**。它的目标，是把企业内部的自有数据变成可以服务于 Agent 落地应用的 AI-Ready 数据，并对业务产生真实价值——而这个目标的本质，就是持续提升 AI 在企业真实场景下的准确度、可信度与可控性。

## 2.2 智能飞轮：数据驱动 AI，AI 反哺数据

MOI 的设计哲学，可以用一个"**智能飞轮**"来概括：**数据驱动 AI、AI 反哺数据。**

- **数据驱动 AI**：高质量、被治理、可检索、有记忆的企业数据，源源不断地为 Agent 提供可信上下文，让 AI 在你的业务场景中越来越聪明、越来越准确；
- **AI 反哺数据**：AI 能力（解析、标注、特征生成、矛盾检测、自动治理）又被反向用于加工和净化数据本身，让数据越用越干净、越用越结构化、越用越有价值。

这个飞轮一旦转动，便会自我强化：数据越好，AI 越准；AI 越准，数据越净；如此循环，企业的数据资产与 AI 能力同步螺旋上升。这正是"**以数生智、以智驭数**"的内涵——用数据生长出智能，再用智能驾驭数据。

## 2.3 解决方案总体架构

为支撑上述理念，MOI 构建了一套自下而上、环环相扣的端到端架构。整体可分为五个层次：

```
┌─────────────────────────────────────────────────────────────┐
│  ⑤ 应用与交互层                                                │
│     工作空间 · 工作流编排 · Chat2BI · 多模态搜索 · API · Agent 接入 │
├─────────────────────────────────────────────────────────────┤
│  ④ 智能与记忆层                                                │
│     混合检索(向量+全文) · 知识库 · Memoria 记忆 · MCP 互操作     │
├─────────────────────────────────────────────────────────────┤
│  ③ 数据工程与治理层                                            │
│     MatrixPipeline 接入解析 · MatrixGenesis 模型服务 · Agentic 治理 │
├─────────────────────────────────────────────────────────────┤
│  ② 超融合数据底座层                                            │
│     MatrixOne：HSTAP / One-Lake / 向量 / 全文 / Git-for-Data     │
├─────────────────────────────────────────────────────────────┤
│  ① 基础设施与运行底座层                                        │
│     MatrixDC 算网调度 · CPU/GPU · K8s · 高吞吐低时延推理环境     │
└─────────────────────────────────────────────────────────────┘
```

- **① 基础设施与运行底座层**：整合 CPU/GPU 算力、容器编排与高速网络，提供大规模并行处理与弹性资源调度，确保 AI 模型推理与数据处理高效运行，并提供高吞吐、低时延的推理环境。
- **② 超融合数据底座层**：以 MatrixOne 数据库为核心，基于 HSTAP 超融合引擎与 One-Lake 架构，统一存储与计算结构化、半结构化、非结构化数据，原生支持向量与全文检索，并通过 Git-for-Data 提供数据版本能力。
- **③ 数据工程与治理层**：由 MatrixPipeline 负责多源接入、解析与 ETL，MatrixGenesis 提供模型服务与 Embedding 能力，并引入面向 Agent 的 Agentic 数据治理机制，确保数据的质量、一致性与可用性。
- **④ 智能与记忆层**：提供向量与全文混合检索、知识库构建、以及由 Memoria 支撑的 Agent 长期记忆能力，并通过 MCP（Model Context Protocol）实现与各类 Agent 的标准化互操作。
- **⑤ 应用与交互层**：用户既可直接使用平台提供的工作空间、工作流编排、Chat2BI、多模态搜索等终端能力，也可通过 API 或将 MOI 作为 MCP 数据/记忆服务接入自有 Agent 应用。

这五层环环相扣，共同构成了一个面向 Agent 的、从数据到智能、从智能再反哺数据的完整闭环。

## 2.4 五大核心创新能力

在 2025 年 9 月的战略产品发布会上，MatrixOne Intelligence 提炼出五大核心创新能力，它们正是 MOI 区别于传统数据平台的关键所在。

### 能力一：融合架构

**一次接入，统一治理。** MOI 以超融合架构为根基，能够一次性接入企业的主流存储、数据库与知识库，统一管理结构化与非结构化数据。企业无需再为不同数据类型引入不同的专用系统——OLTP、OLAP、向量、全文、时序在同一引擎内原生融合，从根本上消除数据孤岛、ETL 搬迁与一致性难题。这是 Agent 能够"一处取数、处处可用"的前提。

### 能力二：Agentic 数据治理

**让治理本身变得智能。** MOI 引入面向 Agent 的数据治理机制，能够根据任务上下文，自动发现、清洗、解析所需数据。传统的数据治理依赖人工定义规则、繁重的手工标注；而 Agentic 数据治理把 AI 能力嵌入治理流程本身——当 Agent 接到一个任务，系统能智能判断需要哪些数据、自动从多源中发现并拉取、按需清洗与解析，把"为 Agent 准备上下文"这件事自动化、规模化。这是智能飞轮中"AI 反哺数据"的核心体现。

### 能力三：智能数据解析

**把非结构化数据炼成可信上下文。** MOI 以 AI 驱动的方式解析 PDF、Office 文档、图片、音频、视频等各类非结构化数据，**结构化准确率达 94%**。无论是 PDF 中的复杂版面与嵌套表格，还是图片中的对象与文字、音视频中的语音与关键帧，MOI 都能高质量地抽取内容与元信息，转化为可被向量化、可被检索、可被 Agent 消费的结构化数据。解析质量，直接决定了喂给 Agent 的上下文是"干净"还是"带毒"——94% 的准确率，正是可信上下文的工程基石。

### 能力四：高性能运行底座

**高吞吐、低时延的推理环境。** Agent 的自主循环对底层数据服务的响应速度极为敏感——每一步规划与行动，都可能伴随多次检索与取数。MOI 提供高吞吐、低时延的运行底座，结合存算分离与弹性调度，确保在大规模并发的 Agent 工作负载下，依然能够稳定、快速地完成数据召回与上下文供给，让 Agent 的"思考-行动"循环不被数据层拖慢。

### 能力五：全链路安全保障

**数据分支 + 秒级恢复，零停机 CDC。** 面向企业级的合规与可靠性要求，MOI 提供全链路安全保障：基于 Git-for-Data 的"**数据分支 + 秒级恢复**"机制，让任何一次危险的数据操作或 Agent 实验都可以在隔离分支中进行、可随时秒级回退；**零停机 CDC（Change Data Capture）** 能力则保障数据在持续变更同步中不丢失、不中断。配合 RBAC 权限、TLS 加密、数据脱敏等手段，构建起多级安全防护体系，让 Agent 的每一次数据访问都安全、可控、可审计。

## 2.5 产品矩阵

MOI 解决方案由一组协同工作的核心产品构成，它们分别对应架构中的不同层次，共同组成完整的技术体系。

### MatrixOne：超融合云原生数据库（数据与记忆底座）

MatrixOne 是 MOI 平台的核心数据管理底座，也是业界**首个把 Git 式版本控制带给数据**的数据库。其核心特性包括：

- **HSTAP 超融合引擎**：在单一系统内原生统一处理事务（OLTP）、分析（OLAP）、全文检索与向量检索，无数据搬迁、无 ETL，以一套 One-Lake 架构承载企业级多模态负载；可替代 MySQL + ClickHouse + Elasticsearch + Pinecone 的传统拼装栈。
- **Git-for-Data（数据的 Git）**：零拷贝即时快照（毫秒级）、时间旅行（查询历史任意时点数据）、分支与合并、秒级回滚、完整不可变审计——让开发者"像管理代码一样管理数据"。
- **融合向量与全文检索**：内置 IVF/HNSW 向量索引与全文检索，直接构建 RAG 与语义搜索，无需引入专用向量数据库。
- **云原生与 MySQL 兼容**：存算分离、K8s 原生、弹性伸缩，可在公有云、私有云、边缘灵活部署；与 MySQL 8.0 高度兼容，极大降低迁移门槛。

正是凭借 Git-for-Data 与超融合能力，MatrixOne 才能胜任"**智能体与应用的数据与记忆底座**"这一定位。

### MatrixPipeline：多模态数据工程平台

MatrixPipeline 是 MOI 的数据接入、解析与治理引擎。它通过自有连接器与可视化编排，统一企业多源数据的采集与转换，针对 PDF、Word、图片、音视频等不同格式提供智能解析、内容抽取与特征工程能力，并内置去重、清洗、归一化、标注等治理流程。配合 MatrixOne 的深度集成，MatrixPipeline 实现无缝的数据流管理与全生命周期追踪，显著降低多模态数据治理的技术门槛。

### MatrixGenesis：AI 模型服务与智能体开发平台

MatrixGenesis 是 MOI 的 AI 服务模块，集中管理各类大模型与 Embedding 模型，简化模型集成与维护，驱动智能应用的敏捷部署。它涵盖从模型托管、精调到推理部署的能力，内置 BERT、CLIP、Qwen、Stable Diffusion 等多种预训练模型，支持用户加载自定义模型，并提供 Agent 工作流的设计与开发能力，帮助企业快速构建面向特定业务场景的智能体应用。

### 多模态智能检索

MOI 提供强大的跨模态检索与语义查询能力，集成向量检索、全文检索与结构化查询，支持文本、图像、音频、视频等多种数据类型的统一检索。其混合搜索机制结合语义理解与自然语言查询，配合多路召回与智能重排，确保结果的相关性与准确性，是 RAG 与上下文工程的核心引擎，也支撑 Chat2BI 等自然语言查询场景。

### Memoria：AI Agent 记忆底座

Memoria 是 MOI 面向 Agent 时代推出的全新产品，被定义为"**世界首个 AI Agent 记忆的 Git**"。它为 AI Agent 提供一个带版本控制的持久化记忆层，解决传统 Agent"会话即遗忘、记忆无版本、易自相矛盾"的根本痛点：

- **Git 级版本控制**：零拷贝分支、即时快照、时间点回滚，让记忆的每一次变更都可追溯、可回退；
- **语义检索**：向量 + 全文混合检索，基于语义召回相关记忆；
- **自治理**：自动检测矛盾、隔离低置信度记忆，从源头抑制幻觉；
- **跨会话持久**：偏好、事实、决策跨越会话边界长期留存；
- **五类记忆**：语义（项目事实与决策）、画像（用户偏好）、程序（工作流与方法）、工作（临时任务上下文）、情景（会话摘要）。

Memoria 基于 MatrixOne 的原生 Copy-on-Write 引擎与 MVCC 构建，并通过 **MCP（Model Context Protocol）** 接入 Cursor、Claude Code、OpenAI Codex、Google Gemini CLI 等任意 MCP 兼容 Agent。它让 Agent 第一次拥有了"可信、可演进、可审计"的长期记忆。

### MatrixDC：高性能算网调度平台

MatrixDC 作为资源底座，通过 K8s 容器、RDMA 高速网络、对象存储等基础能力，把 CPU 与 GPU 服务器统一纳管、组网、调度与运营。它支持 Serverless 化的资源调用与弹性扩缩，具备低延迟、高吞吐的网络优化能力，是多模态 AI 任务运行与大模型训练/推理的强大技术基石。

## 2.6 技术特点与优势

综合上述能力与产品，MOI 在以下六个方面展现出显著优势：

- **一站式端到端平台能力**：覆盖从数据接入、治理、解析、存储、检索到 Agent 接入的全流程，企业无需在多套独立系统间迁移数据或自行拼装，大幅降低实施复杂度与开发成本。
- **弹性高效的资源调度**：云原生 + Serverless 架构，CPU/GPU/存储按需扩展、动态调度，存算分离进一步增强灵活性与经济性，从容应对 Agent 工作负载的剧烈波动。
- **超融合 One-Lake 数据底座**：以单一引擎统一承载多模态、多负载，相比传统多系统架构，极大简化数据管理、减少架构与运维投入，快速释放数据潜能。
- **Git-for-Data 版本与审计**：数据、知识库与记忆均可版本化、可分支、可回溯、可审计，既满足合规与审计要求，又加速 AI 迭代，是 Agent 可信落地的底层保障。
- **AI 驱动的高效治理与解析**：内置 AI 能力自动完成多模态数据的提取、标注、解析与治理（94% 解析准确率），快速构建高质量 AI-Ready 数据资产。
- **Agent 原生记忆与 MCP 互操作**：通过 Memoria 提供可演进、可审计的 Agent 长期记忆，通过 MCP 实现 Agent 即插即用，让 MOI 成为 Agent 生态中的标准数据与记忆中枢。
